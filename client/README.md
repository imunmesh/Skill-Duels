# SkillDuels - Client Frontend (Student 3)

This directory is designated for the React frontend application (Student 3 ownership).

### Expected Responsibilities:
- Auth pages (Login, Register with form validation and JWT storage).
- Lobby and matchmaking screen.
- Real-time quiz battle screen (synced with Socket.IO match engine).
- Result screen and profile/leaderboard dashboard.

### Environment Setup:
Create a `.env` file in this directory with:
```env
VITE_API_BASE_URL=http://localhost:5000/api
VITE_SOCKET_URL=http://localhost:5000
```
